# 하치와레의 작은 풀밭

기존 자기소개 페이지와 분리된 독립적인 정적 사이트입니다.

- 이 폴더의 `index.html`을 Chrome 또는 Edge로 열면 실행됩니다.
- 서버에서 제공할 때는 `/hachiware/`로 접속합니다.
- `style.css`, `app.js`, `assets/`는 하치와레 전용 파일입니다. 폴더 전체를 함께 유지하세요.
- 얼굴 있는 노란 별을 누르면 매지컬 하치와레로 변신하고, 다시 누르면 원래 모습으로 돌아옵니다.
- 쓰다듬기, 간식 주기, 놀이, 쉬어가기와 친밀도 저장을 지원합니다.

저장소 루트의 `index.html`, `main.html`, `style.css`, `img/` 및 `자기소개 페이지/`는 기존 자기소개 사이트입니다.
